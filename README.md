# GARAGE ONE

Коммерческий универсальный русскоязычный лендинг автосервиса.

## В прототипе
- адаптивный mobile-first дизайн;
- каталог из 16 направлений;
- интерактивный подбор проблемы;
- калькулятор стоимости;
- онлайн-запись;
- блок до/после;
- trust-блок;
- sticky mobile CTA.

## Следующий production-этап
Подключить Supabase/CRM, Telegram-уведомления, реальный календарь, админку, SEO-страницы, WebGL-автомобиль, аналитику и CMS.
